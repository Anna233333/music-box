The governing rule

No rotation, no new notes.

The user supplies the energy. Moving the crank changes the system from idle to playing. Each 2° step advances the mechanism and keeps the recording flowing while the crank moves.

Releasing the handle stops the cylinder immediately, while the final metal note is allowed to fade naturally.
